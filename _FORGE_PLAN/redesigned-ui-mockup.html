■ DESIGN SYSTEM — "QUIET POWER"

  • Inter font: Premium typeface with optical sizing. Clean, modern, highly legible at all sizes.
  • Zinc neutral palette: #09090B background, #111113/#18181B surfaces, #27272A borders. Deeper, richer darks than before.
  • One accent: Ember #FF6B3D used sparingly — logo, send button, active states, toggles. Never for decoration.
  • Softer surfaces: Cards use #111113 on #09090B — barely-there contrast that feels premium, not harsh.
  • Generous whitespace: 24px padding on screens, 16-20px between elements. Room to breathe.
  • Subtle shadows: Phone frames have soft ambient shadows. Logo and send button have colored glows.
  • Refined typography: 600 weight titles, 400 body, 500 labels. Tight letter-spacing (-0.3px) on headings.
  • Pill input bar: Fully rounded 24px radius, integrated send button, subtle border.
  • Status dots: Tiny 5-6px circles with semantic color. No harsh badges or borders.
  • Minimal tool chips: Compact, monospace, muted. Status shown by dot color, not background.
  • Drawer active state: Ember left-border + 6% tint background. Clean and unmistakable.
  • Toggle switches: Larger 48x28, smooth animation, ember when on.
  • No emoji in UI chrome: Emoji only in content (module icons), never in navigation or buttons.
  • Accessibility: #A1A1AA on #09090B = 8.9:1 contrast (WCAG AAA). #52525B used only for non-essential text.
